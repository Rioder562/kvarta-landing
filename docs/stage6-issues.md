- **Описание:** новый untracked-файл `tests/api-orders.test.ts` содержит два некорректных импорта:

- **Последствия:**

  - `npm run build` не зелёная (сбой type check), то есть текущее состояние проекта не может быть упаковано в production-сборку без правок.
- **Воспроизведение:** `node --test tests\api-orders.test.ts` (Node 24) → `ERR_MODULE_NOT_FOUND: Cannot find module '…\node_modules\next\server'`; `npm run build` → `Running TypeScript ... tests/api-orders.test.ts(8,22): error TS2307: …`.

## 3. (Информационно) Запись в dev-БД через cmd-шелл искажает кириллицу

- **Описание:** POST, отправленный через PowerShell/cmd-шелл с прямой кириллицей в JSON-теле, сохраняется в БД как `?` (codepoint U+003F) — это перекодирование на стороне шелла (cp866/UTF-16 → UTF-8), а не ошибка приложения. Тот же текст, отправленный через `node fetch` (UTF-8), сохраняется корректно (проверено: `id 7`, `selection = «Эфиопия Иргачеффе»`, коды 42d 444 438 …).
- **Серьёзность:** отсутствует — поведение приложения корректно; зафиксировано, чтобы не путать с реальным дефектом.
- **Воспроизведение:** сравнить хранение строк, отправленных через `Invoke-WebRequest` с телом, собранным в PowerShell, и через `node -e fetch(...)`.
