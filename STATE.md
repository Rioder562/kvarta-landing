## Выбранные решения

### Визуальный характер
- «Рабочая записная книжка обжарщика»: бумажный фон, чернильный текст, моноширинные технические детали.
- Палитра (без градиентов):
  - фон `#F7F1E8`; текст `#2A211A`; акцент `#B4551D`; линии/карточки `#E4D9C6`
- Типографика без webfonts: заголовки — системный serif (Georgia-семейство), тело — системный sans, технические подписи — `ui-monospace`.
- 1px-рамки, пунктирные разделители (тема «оторванный талон»), скругления 4px, без теней.
- Анимации отсутствуют; допущены только hover/focus-переводы 150ms.

### Структура страницы (списочная)
1. Шапка: вордмарк «Кварта», строка «Минск · обжарка по четвергам», якорная навигация (Кофе, Подписка, Доставка, Контакт).
2. «Обжарка» — карточка «талон обжарочной партии»: четверг, партия 5 кг, список сортов, «зерно приезжает через 1–3 дня», CTA-кнопки.
3. «Что в этой обжарке» — 4 карточки (3 направления + дрип-пакеты) с характеристиками, объёмом, ценой.
4. «Подписка» — 2×250 г/мес, 54 BYN/мес, бесплатная доставка, CTA.
5. «Как это устроено» — очередь: обжарка (чт) → доставка по Минску (пт) → самовывоз (часы, адрес).
6. «Мастерская» — Аня и Дмитрий, бывшие бариста, партии 5 кг с 2019, ул. Короля, 9.
7. Форма заявки: тип (разовый/подписка), название, телефон, комментарий → POST в SQLite (этап 3).
8. Футер: адрес, часы самовывоза, «доставка по пятницам, бесплатно от 50 BYN».

### Мобильная версия
- Одна колонка, без горизонтального скролла.
- Липкая нижняя CTA-панель (появляется после прокрутки талона): «Подписка · 54 BYN/мес» + «Подать заявку».
- Поля форм ≥16px font-size; кнопки 48–56px; элементы в одну строку.
- Выбор типа заявки — сегментированный переключатель.

### Данные и коды
- SQLite: одна таблица `orders` (`id`, `created_at`, `name`, `phone`, `kind` ∈ {one-off, subscription}, `selection`, `comment`). Прочитать через `better-sqlite3` в `lib/db.ts`.
- POST `/api/orders` — validation + insert; ответ JSON `{ ok, id }`.
