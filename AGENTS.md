## Windows: запуск и проверка сервера

- Для запуска dev-сервера используй `powershell -NoProfile -ExecutionPolicy Bypass -File "D:\AI-Projects\work\start-server.ps1"`.
- Не запускай долгоживущие процессы непосредственно из Bash-инструмента OpenCode.
- Не выполняй глобальный поиск файлов через glob по всему диску.
- Поиск по проекту ограничивай каталогом проекта.
- Не запускай длительные циклы ожидания готовности сервера.
- Проверяй доступность сервера отдельным запросом с таймаутом не более 5 секунд.
- Если инструмент завис или не вернул результат, не запускай повторный вызов поверх незавершённого.
- Не удаляй БД, журналы и другие данные без проверки необходимости и согласования.
